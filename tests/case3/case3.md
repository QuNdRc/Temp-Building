# Кейс 3 «Модель, смета, график» (хардкор, 3–4 часа)

Заказчик передал **BIM-модель IFC4** (`case3_model.ifc`, текстовый STEP) четырёхэтажного корпуса с кровлей, **чертёж 2-го этажа** (`plan_L2.png`) и **цены** (`prices3.csv`). Нужно проверить качество модели, посчитать по ней смету и срок каркаса.

Можно использовать любые библиотеки (ifcopenshell и т. п.) или писать разбор руками. Эталон написан **без** библиотек.

**Честные оговорки:**
- Файл собран вручную по стандарту IFC4 и проверен моим собственным независимым парсером. **В сторонних программах (Revit, BlenderBIM, IfcOpenShell) я его не открывал**, у меня их нет. Если где-то файл не открывается, это ошибка файла, а не твоя.
- Единицы измерения **нужно читать из файла** (`IfcUnitAssignment`), а не угадывать.
- Подсказок «где ошибки» нет: в модели намеренно заложены дефекты, их нужно найти правилами из этого документа.
- Объёмов в `Qto_*` верить нельзя: они лежат в файле, но не обязаны быть правдой.
- Приоритет, если не успеваешь: 3 → 2 → 4 → 5 → 1 → 6.

## Состав модели (для ориентира)

Площадка 30 × 12 м, 4 этажа `L1…L4` + кровля `Roof`. На каждом этаже: наружные стены (кирпич), внутренние бетонные стены и перегородки, колонны, плита перекрытия, окна и двери. Геометрия элементов задана выдавливанием прямоугольного профиля; положения заданы **цепочками** `IfcLocalPlacement` (дверь относительно стены, стена относительно этажа).

Что надо знать про сущности: `IfcOpeningElement` вырезает проём в стене или плите (`IfcRelVoidsElement`); `IfcDoor`/`IfcWindow` стоят в проёме (`IfcRelFillsElement`); материал даёт `IfcRelAssociatesMaterial`; свойства лежат в `IfcPropertySet`, количества в `IfcElementQuantity`.

## Задание 1. Инвентарь

Посчитать число элементов по классам (`IfcWall`, `IfcSlab`, `IfcColumn`, `IfcDoor`, `IfcWindow`) на каждом этаже. Этаж определять **по геометрии**: элемент относится к этажу `E`, если его середина по высоте лежит в диапазоне `[отметка_E − 0,2 м ; отметка_E + 2,8 м]`. Дубликаты считать как есть. Проёмы (`IfcOpeningElement`) не считать.

## Задание 2. Чистые объёмы

Для стен, плит и колонн: **чистый объём** = объём прямоугольной призмы − Σ объёмов пересечения с проёмами, вырезающими этот элемент. Свести по этажу и материалу, м³.

## Задание 3. Проверки качества модели

Для каждого правила вернуть **список `GlobalId`** нарушителей:

| Правило | Условие нарушения |
|---|---|
| R1 | у стены, плиты или колонны нет материала |
| R2 | `NetVolume` из Qto отличается от вашего чистого объёма более чем на 2% |
| R3a | дверь с `Pset_DoorCommon.FireExit = TRUE` уже 1000 мм |
| R3b | любая дверь уже 800 мм |
| R4 | наружная стена (`Pset_WallCommon.IsExternal = TRUE`) без `FireRating` |
| R5 | дубликат: тот же класс и та же геометрия (габариты с точностью 1 мм) уже встречались; вернуть **второй** из пары (по порядку в файле) |
| R6 | этаж, к которому элемент привязан в `IfcRelContainedInSpatialStructure`, не совпадает с этажом по геометрии (правило из задания 1) |
| R7 | колонна пересекается по объёму (больше 0) с любой не-дубликатной стеной |
| R8 | проём в стене, который не заполнен дверью или окном (`IfcRelFillsElement`) |

## Задание 4. Смета

Только после очистки: **исключить дубликаты (R5)**, брать **геометрический** чистый объём. Если у элемента нет материала, принять по умолчанию: колонна → `Concrete B30`, плита и стена → `Concrete B25`.

- Бетон и кирпич: чистый объём × цена за м³.
- Арматура (кг на м³ чистого бетона): плиты 110, бетонные стены 80, колонны 180; кирпичные стены без арматуры. Цена из таблицы.
- Окна: число `IfcWindow` × цена. Двери: число `IfcDoor`; двери с `FireExit = TRUE` по цене эвакуационной, остальные по обычной.

Выход: общая стоимость, ₽.

## Задание 5. График каркаса

Объёмы и масса арматуры берутся из задания 4. Нормы: арматурщики 1200 кг/сут, бетононасос 60 м³/сут (округлять вверх), кладка 15 м³/сут; опалубка плиты 3 суток, выдержка плиты 7, выдержка колонн и стен 3.

Для каждого этажа `k = L1…L4` по порядку:
1. плита этажа `k`: опалубка (3) → армирование (⌈кг/1200⌉) → бетонирование (⌈м³/60⌉) → выдержка (7);
2. затем колонны и бетонные стены этажа `k`: армирование → бетонирование → выдержка (3);
3. кирпичные стены этажа `k` (⌈м³/15⌉) начинаются после выдержки колонн и стен и идут **параллельно** дальнейшим работам.

После колонн и стен `L4`: плита кровли (опалубка 3 → армирование → бетонирование → выдержка 7).
**Срок = max( конец плиты кровли, конец кирпичной кладки L4 )**, сутки.

## Задание 6. Сверка с чертежом

На `plan_L2.png` нарисован этаж 2 (оси в метрах, линейка есть). Найти, чем чертёж **отличается** от модели IFC на этаже `L2`. Ответ: что, где (координаты в метрах), как проверил.
